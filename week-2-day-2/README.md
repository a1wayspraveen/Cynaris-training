# Responsive Landing Page

## Project Overview

This project is a fully responsive landing page built using HTML and CSS. The design follows a mobile-first approach and adapts to different screen sizes using media queries.

## Features

* Mobile-first responsive design
* Flexbox navigation bar
* CSS Grid feature section
* Responsive testimonials section
* Footer section
* Media queries for tablet, desktop, and large desktop screens

## Breakpoints Used

* Mobile: 320px
* Tablet: 768px
* Desktop: 1024px
* Large Desktop: 1440px

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Git & GitHub
